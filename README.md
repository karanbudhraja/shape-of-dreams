# shape-of-dreams
Mod(s) for Shape of Dreams

## How to Build

1. Replace `~` in `HideVersionMod.vdf` to full home directory path
2. Open your terminal or command prompt inside the project root folder
3. Run the following command to compile the codebase:

```bash
dotnet build -c Release
```

## Installation

Once the compilation succeeds, the `DLL` file will be generated in the output build directory: `bin/Release/net8.0/`
